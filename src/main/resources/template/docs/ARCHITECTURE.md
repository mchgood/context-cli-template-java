# 上下文工程模板架构

`ContextManager` 管理六类上下文：系统提示词、会话消息、工具消息序列、长期记忆、相关上下文、结构化输出提示。按固定顺序组装每轮请求；会话和工具消息按消息边界裁剪。

`LlmClient` 通过 Java HttpClient 请求兼容 OpenAI Chat Completions 的 DeepSeek API，保留响应中的工具调用 JSON。`Agent` 负责模型与工具的循环、工具结果回填及最大轮次限制。`ToolManager` 注册工具、声明 JSON Schema、执行工具，并限制文件访问在工作目录内。

`Evaluation` 提供事件总线与简单的工具调用/耗时统计；可扩展为持久化 trace 与数据集评估。示例采用单次进程内存，会话记忆不会跨重启持久化；多 Agent 编排与流式响应未实现。

边界：这是教学用起点。生产使用需补齐鉴权、脱敏、超时重试策略、并发隔离、持久化、观测与针对具体模型的兼容性验证。
